# TUGAS 1 – AKUISISI DATA

**Mata Kuliah:** Akuisisi dan Manajemen Data  
**Program Studi:** Informatika – INSTIKI  
**Topik:** Akuisisi Data Tempat Wisata di Bali Menggunakan API OpenStreetMap

## 1. Deskripsi
Proyek ini bertujuan mengambil data tempat wisata di Bali menggunakan API Overpass dari OpenStreetMap. Data yang diperoleh kemudian diolah menggunakan Python dan disimpan dalam format CSV dan JSON.

## 2. Sumber Data
- Nama: OpenStreetMap
- Website: https://www.openstreetmap.org/
- API: https://overpass-api.de/api/interpreter
- Lisensi: Open Database License (ODbL)

## 3. Metode Akuisisi
Metode yang digunakan adalah API dengan bahasa pemrograman Python melalui Google Colab.

## 4. Isi Dataset
Dataset memiliki informasi:
1. Nama tempat wisata
2. Kategori
3. Latitude
4. Longitude
5. Website
6. Alamat
7. Tipe objek OpenStreetMap
8. ID objek OpenStreetMap

## 5. Etika Pengambilan Data
Pengambilan data dilakukan dari sumber publik dengan memperhatikan ketentuan API, lisensi ODbL, penggunaan User-Agent, dan jeda permintaan. Atribusi OpenStreetMap tetap dicantumkan.

## 6. Cara Menjalankan
1. Buka Google Colab.
2. Buka notebook akuisisi_tempat_wisata_bali.ipynb.
3. Jalankan seluruh cell secara berurutan.
4. Periksa jumlah data yang diperoleh.
5. Simpan hasil CSV dan JSON.

## 7. Hasil
Dataset ditargetkan memiliki minimal 100 record dan minimal 5 kolom bermakna.
